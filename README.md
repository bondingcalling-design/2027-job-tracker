#   2027 秋招投递台

面向 B 端产品、能源电力、AI+能源和知识图谱方向的秋招机会与投递进度看板。

## 接手修改

- 核心交互页面：`app/dashboard.tsx`
- 默认企业与岗位数据：`lib/opportunities.ts`
- 筛选审核与薪资证据：`lib/screening.ts`
- 本地进度合并与去重：`lib/opportunity-state.ts`
- 全局样式：`app/globals.css`
- GitHub Pages 本地保存适配：`github-pages/src/main.tsx`
- GitHub Pages 页面元信息：`github-pages/index.html`
- 自动发布流程：`.github/workflows/pages.yml`

## 本地运行

```bash
pnpm install
pnpm dev
```

静态版构建：

```bash
pnpm build:pages
```

构建结果位于 `pages-dist/`。推送到 `main` 分支后，GitHub Actions 会自动更新 GitHub Pages。

## 数据保存说明

GitHub Pages 版本使用浏览器本地存储保存投递阶段、收藏、备注和日期。换电脑或清理浏览器数据前，请先在网页中导出 JSON，之后可通过“导入 JSON”恢复。

## 2026-10-12 筛选规则

- 新增及尚未准备的默认推荐：本科可投，优先 B 端、AI、能源产品。检索岗位名扩展到产品工程师、产品规划、技术产品、业务/需求分析、解决方案和售前技术，不再只按“产品经理”四个字判断。
- 仍排除字节、美团、拼多多、腾讯这类互联网超大厂；汇川、远景、禾赛、速腾、招银网络、货拉拉、九号、TCL、SHEIN 等产业科技或平台企业按具体岗位审核。
- 私企常规推荐月薪区间下限至少1万元；允许同届同岗招聘转载或往届同城同类校招参考，必须标出来源和不确定性。不能拿资深社招工资、公司全部岗位区间或年包除以12冒充基本月薪。央国企不设统一硬门槛，但明确低薪且与简历不匹配的岗位也会撤下。
- 高薪私企解决方案岗、待遇好的央国企、外企或官方明确工作节奏友好的岗位可以破格进入，但必须在 `exceptionReason` 写明破格理由和客户侧、出差、销售或交付风险。
- 已经标为“准备中”及有后续投递进度的旧条目继续显示；“放弃”仍隐藏。筛选不会删除保存的进度、备注或导出备份。

- 10月12日重新逐岗审核全部银行机会：撤下已截止的中国银行、招行成都，具体岗位要求研究生的苏州银行，公开仅8–11K且岗位过泛的广发银行，以及与产品简历不匹配的民生科技纯开发/运维岗。当前默认69条。
- 银行岗只保留6条：宁波银行产品经理、北银金科AI产品经理为高匹配；交通银行大连分行金融科技储备生为需求/产品相邻岗；浙商银行、杭州银行和中信信用卡中心仅按明确的AI/产品子方向保留。中信和交行10月18日截止，浙商和杭州银行10月25日截止，宁波银行10月31日截止；北银金科当前未公布统一截止。
- 其他重要截止：远光软件与国网数科10月30日、华能北京热电10月31日、绿盟科技保守按11月15日、中兴新云和精智达12月31日；顺丰科技、北银金科、金蝶和金风未公布统一截止，按官网岗位状态滚动投递。
- 10月9日按使用反馈隐藏桌面列表的“下一步”整列；原有下一步日期不会删除，仍可在编辑窗口中维护，并继续用于已投递岗位的提醒。
- 页面支持“同阶段·最近修改 / 同阶段·最早修改”排序并可一键切换倒序；点击整行可展开详情；“查看已放弃”只在需要复盘时显示放弃记录，默认不占列表位置。
- 每个新增种子都需在 `screeningReviews` 中完成审核，否则不会进入默认推荐。学历/岗位不符的旧下架记录仍不展示。
- 薪资和破格依据可在详情中查看。页面不再展示招聘群的通用“本周时间点”；只有岗位阶段为“已投递/笔试/面试/Offer”且填写了“下一步日期”时，才显示个人流程提醒。
